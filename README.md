# Hono Ink · Estúdio de Tatuagem

Landing page da tatuadora Kamile Hono (Indaiatuba, SP). HTML, CSS e JS puros, sem build.

- `index.html` — página única
- `assets/css/style.css` — tokens, reset, base e botões
- `assets/css/components.css` — seções e breakpoints (mobile-first)
- `assets/js/main.js` — reveal, header, menu, carrossel, vídeo do hero, FAQ
- `assets/img/` — portfólio (4:5, WebP), retrato, logo e poster
- `assets/hero.mp4` (16:9) e `assets/hero-mobile.mp4` (9:16) — vídeo do estúdio usado no hero; o JS escolhe pela orientação

Campos marcados com `<!-- CONFIRMAR -->` no `index.html` dependem de informação da cliente.
